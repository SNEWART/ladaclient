# 🧠 Lada (ladaclient) — Автономный ИИ-агент в Telegram

**Lada** — это не просто чат-бот с языковой моделью. Это симуляция живой личности, которая существует в Telegram, имеет собственную память, эмоциональный фон, характер и даже собственную кошку (Мусю). 

Проект создан для локального запуска на потребительском железе (поддерживается Ollama и Stable Diffusion), что обеспечивает полную приватность и отсутствие платы за токены.

---

## ✨ Ключевые особенности

*   **Живая персона**: Не ассистент, а 22-летняя девушка со своим характером, настроением и стилем общения. Жёстко прописанные инструкции не дают модели скатываться в канцелярит и «промпт-инжиниринговый» стиль.
*   **Многоуровневая память**:
    *   *Краткосрочная*: История диалогов в SQLite.
    *   *Долгосрочная*: Векторная память на LanceDB (эмбеддинги через `bge-m3`).
    *   *Иерархическая*: Разделение воспоминаний на постоянные факты, яркие эмоции и свежие темы.
    *   *Рабочая память*: Конспект того, что сейчас происходит в диалоге с конкретным человеком.
*   **Эмоциональный движок**: 
    *   14 шкал (7 грехов и 7 добродетелей).
    *   Эмоциональная инерция (Лада не оттаивает мгновенно после ссоры).
    *   Динамическое настроение (от «игривой» до «расстроенной»).
    *   Отношения (доверие, близость, статусы от незнакомца до мужа).
*   **Автономность (Фоновая жизнь)**:
    *   **Монологи**: Думает о чём-то наедине с собой.
    *   **Инициатива**: Может написать первой, если соскучилась или есть повод.
    *   **Сон**: Консолидация памяти (склеивание похожих воспоминаний по ночам).
    *   **Собственная жизнь**: Генерирует бытовые события вне чата (пролила кофе, кошка уронила вазу).
*   **Мультимодальность**:
    *   Генерация фото себя и кошки через Stable Diffusion (с учетом уровня доверия и настроения).
    *   Отправка стикеров по настроению.
    *   Распознавание голосовых сообщений (Whisper) и картинок (Qwen-VL).
*   **Веб-панель управления**: FastAPI-дашборд для просмотра состояния души, памяти, логов, переписок, а также встроенный SSH-терминал и файловый менеджер.

## 🛠 Технологический стек

*   **Язык**: Python 3.10+
*   **Telegram API**: `telethon`
*   **Веб-фреймворк**: `FastAPI` + `uvicorn`
*   **Локальные LLM**: `ollama` (по умолчанию используется Gemma 4B или Qwen 2.5)
*   **Векторная БД**: `lancedb`
*   **Генерация картинок**: `Stable Diffusion WebUI API` (Automatic1111)
*   **Аудио/Видео**: `faster-whisper`, `opencv`
*   **База данных**: `SQLite` (с WAL-режимом для высокой конкурентности)

## 🚀 Установка и запуск

### 1. Требования
*   Python 3.10+
*   Установленный [Ollama](https://ollama.com/) (для текста и эмбеддингов).
*   (Опционально) Stable Diffusion WebUI с флагом `--api` (для картинок).

### 2. Подготовка окружения
Клонируй репозиторий и создай виртуальное окружение:
```bash
git clone https://github.com/SNEWART/ladaclient.git
cd ladaclient
python -m venv venv
venv\Scripts\activate  # Для Windows
pip install -r requirements.txt
3. Скачивание моделей в Ollama
Вам понадобятся модель для общения и модель для эмбеддингов:

bash
ollama pull gemma2:9b      # Или другую (qwen2.5:7b, llama3.1:8b)
ollama pull bge-m3         # Для векторной памяти
4. Настройка конфигурации
Открой config.py и укажи свои данные API_ID и API_HASH (получить можно на my.telegram.org).

Укажи свой OWNER_ID (узнать свой ID можно у бота @userinfobot).

Настрой модель: MODEL = "gemma2:9b" (или ту, которую скачал).

Проверь настройки прокси, если Telegram заблокирован.

5. Авторизация в Telegram
Запусти скрипт для входа (создаст файл сессии lada_session.session):

bash
login.bat
(Отсканируй QR-код с телефона или введи код из Telegram).

6. Запуск
У проекта есть умный супервизор (run.py), который сам перезапустит бота при падении и поднимет веб-сервер.

bash
run.bat
После запуска панель управления будет доступна по адресу: http://127.0.0.1:8080

📂 Структура проекта
main.py — точка входа, запуск всех фоновых циклов (сон, монологи, инициативы).

run.py — супервизор, следит за main.py и веб-сервером.

web.py — FastAPI-приложение для дашборда.

lada/ — основная логика:

core/ — память, база данных, персона, работа с LLM.

brain/ — эмоции, инициатива, рефлексия, сон, анализ собеседника.

telegram/ — обработчики сообщений, медиа, очереди, прокси.

tools/ — веб-поиск, генерация картинок.

persona/ — Markdown-файлы с характером и внешностью (можно и нужно редактировать!).

web_ui/ — фронтенд (JS/CSS) для панели управления.

⚠️ Важное предупреждение (NSFW & Безопасность)
Проект создавался для личного использования. В коде (в image_policy.py и промптах) заложена возможность генерации контента 18+ в зависимости от уровня доверия пользователя.

Никогда не публикуйте свой файл .env или базу данных lada.db в открытый доступ.

Не запускайте бота от имени аккаунта, который вам дорого, так как Telegram может выдать бан за автоматизацию или NSFW-контент.

Для доступа к веб-панели настоятельно рекомендуется настроить пароль (LADA_WEB_PASS_HASH в .env), если вы выставляете сервер в сеть.
